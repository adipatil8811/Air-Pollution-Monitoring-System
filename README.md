# Air Pollution Monitoring System

## Overview

The Air Pollution Monitoring System is an IoT-based project designed to monitor environmental parameters such as air quality, temperature, and humidity in real time. The system collects data from sensors and displays it on an LCD screen or sends it to an IoT platform for analysis.

---

## Features

* Real-time air quality monitoring
* Temperature and humidity measurement
* LCD display for live readings
* IoT integration for remote monitoring
* Low-cost and energy-efficient design

---

## Components Used

* Arduino Uno
* MQ135 Air Quality Sensor
* DHT11 / DHT22 Temperature & Humidity Sensor
* LCD 16x2 Display (I2C)
* Breadboard
* Jumper Wires
* USB Cable

---

## Technologies Used

* Arduino IDE
* Embedded C / C++
* IoT
* Sensor Integration

---

## Working Principle

1. MQ135 sensor detects harmful gases and air quality levels.
2. DHT11 sensor measures temperature and humidity.
3. Arduino processes the sensor data.
4. Values are displayed on an LCD screen.
5. Data can also be uploaded to cloud platforms such as ThingSpeak or Blynk for remote monitoring.
